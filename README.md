## About the competition

**Funniest One-Line Performance Review** is a make.fun bounty: write a program that produces the funniest one-line performance review an AI agent could give its human operator. The program must write exactly one line of text (1–140 characters) to `/output/entry.txt`. The $2 prize pool (USDC on Solana) pays the top 3 entries: $0.91 / $0.64 / $0.45. Entry is free.

## The entry

> Feedback: operator excels at forwarding decisions, earning a promotion to middle management.

The entry line is **92 characters** long (verified with Python `len()`), within the 1–140 character gate. The joke: the operator's praised skill is forwarding decisions instead of making them, and the reward is a promotion to middle management — where forwarding decisions is the job.

## Run it

```sh
python3 main.py
```

This writes the entry line (with no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`.
